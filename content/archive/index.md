## Options for these notes

### Keep on GitBook (default)

Leave them where they are and link here. Add a new **AI Infrastructure** section in the same GitBook space for quick notes from your phone.

### Move them here

1. Every GitBook page has a Markdown version: add `.md` to its URL, or export the space.
2. Copy the files into `content/archive/`. Each file becomes a page automatically.
3. Link them in the table below.

### Sync both ways

GitBook's **Git Sync** can link a GitBook space to a GitHub repo, so edits in either place show up in the other. Point it at a separate repo (not this one's `content/`) to avoid conflicts with the roadmap.
