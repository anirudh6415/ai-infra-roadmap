# Projects

Four portfolio projects, one per phase, each building on the last. Together they tell one story: **measure → understand → scale → plan.**

The project cards above are generated from each project page. Change a project's status in the `Status:` line at the top of its page (⬜ → 🟨 → ✅).

## Every project page has

1. **Goal**: the question it answers.
2. **Why it matters**: for capacity work and for interviews.
3. **Setup**: hardware, models, tools.
4. **Milestones**: tied to roadmap weeks.
5. **Deliverables**: repo, charts, post.
6. **Stretch goals**: only if you're ahead.
7. **Interview story**: how you'll talk about it.
8. **Results & lessons**: fill in when done.

## Repo conventions

- One public repo per project (e.g. `llm-capacity-bench`, `kernel-lab`), linked from here.
- Every repo has: a README with the headline result at the top, a `results/` folder with raw CSVs, a `charts/` folder, and exact reproduction steps (GPU, driver, library versions).
- Record the cost of any rented GPU time in the README.
